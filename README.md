# The Magic iPod Comeback Edition

A browser-based mashup game where you pair early-2000s hip-hop songs with rock/indie artists to discover what happens when two worlds collide.

Reworked in 2026 by [Mr_DannyOfficial](https://github.com/DannyWright93) — based on the original **Magic iPod** by Race Archibold (2017).

---

## How to Play

**Desktop:** Drag a hip-hop song tile onto a rock artist tile (or vice versa) to play their mashup.

**Mobile:** Tap a song or artist to select it — compatible matches will highlight. Tap one to play.

Not every combination works. Part of the fun is figuring out which ones do.

---

## What's Inside

- **21 hip-hop songs** — Jay-Z, Kanye, Eminem, DMX, Ludacris, 50 Cent, Lil Jon, and more
- **23 rock/indie artists** — Fall Out Boy, Green Day, Weezer, MCR, Paramore, RHCP, and more
- **148 mashup audio clips**

---

## Tech

Vanilla HTML/CSS/JS — jQuery UI for drag-and-drop, touch-punch for mobile support. No build step, no dependencies to install.

Just open `index.html` in a browser. Or visit https://magicipodcomeback.netlify.app/
